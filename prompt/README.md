# 提示词脚本集

本目录收录可直接交给 AI 使用的提示词模板，涵盖代码重构、iOS 产品开发、图片编辑和图表报告生成。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `FastAPI项目渐进式重构与代码审查.md` | 在保持接口与业务行为兼容的前提下，分析、审查并逐步重构现有 FastAPI 项目。 |
| `iOS应用产品设计与SwiftUI开发.md` | 指导 AI 从产品架构、设计系统到 SwiftUI 实现，完成高质量原生 iOS 应用。 |
| `照片遗物风编辑艺术.md` | 使用 `photo-relic-editorial` Skill 将照片制作成 Photo Relic 风格作品。 |
| `拾景纸刊海报.md` | 使用 `scenes-gathered-zine` Skill 将照片制作成拾景纸刊风格海报。 |
| `旅行记忆手卡.md` | 使用 `travel-memory-card-duo` Skill 将照片制作成旅行记忆卡片。 |
| `摄影与抽象面板编辑作品.md` | 使用 `photo-abstract-editorial` Skill 制作摄影与抽象面板组合的编辑作品。 |
| `躺平图表报告.md` | 使用 `lieflat-charts` Skill 根据任务内容生成图表报告。 |

## 使用方式

1. 打开与任务对应的 Markdown 文件。
2. 补充项目说明、图片或其他必要材料。
3. 将完整内容发送给支持相应 Skill 的 AI。

部分模板依赖第三方 Skill，使用前请根据文件中的 GitHub 地址完成安装或配置。
